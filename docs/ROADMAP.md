# Roadmap

## Current foundation

- Isolated candidate workspaces
- Counterfactual candidate comparison
- Causal Genome lifecycle
- Anti-Gene / quarantine / lineage
- ChronoForge sequential repository aging
- Claim Ledger
- Research-run manifest validation
- Experiment artifact fingerprints
- CI across Python 3.11 / 3.12

## Next

### 1. Benchmark harness

Build a repository/task benchmark runner that records:

- repository snapshot;
- task definition;
- model/scaffold;
- cost and wall time;
- candidate patches;
- present-time tests;
- future-generation survival;
- artifact bundle.

### 2. Matched baselines

Compare LR-Agent mechanisms against:

- present-tests-only;
- no-Genome;
- no-ChronoForge;
- non-inherited future prompts;
- simple heuristic candidate ranking.

### 3. Statistical reporting

Add repeated runs, paired comparisons, confidence intervals and failure-case retention.

### 4. Reality calibration

Use observed maintenance events to compare forecasted future-risk weights against simple baselines.

## Later

- Chrono Tournament
- Temporal Anti-Gene

- Intent Recoverability metric
- Future Regret analysis

## Explicit non-goals

- claiming general coding-agent superiority without held-out evaluation;
- hiding negative results;
- turning exploratory scalar metrics into universal software-quality scores.
